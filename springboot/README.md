# Spring Boot

Spring Boot is the application foundation for NIET Events.

## Responsibilities

- Application startup and dependency management.
- Spring MVC controllers and REST controllers.
- Service-layer transactions and business rules.
- Configuration for Oracle, JSP, validation, and security.
- Error handling and common application responses.

## Planned packages

```text
src/main/java/com/niet/events/
  config/
  common/
  auth/
  event/
  registration/
  crowd/
  announcement/
  certificate/
  notification/
```

## Branch

Develop Spring Boot framework work on `feature/springboot/*`, then merge tested changes into `feature/fullstack` and finally `main`.
