# Full Stack Integration

This folder represents features that connect the Spring Boot, JSP, security, JDBC, and Oracle workstreams.

## End-to-end features

- Login and role-based dashboard routing.
- Organizer event creation and publication.
- Student event browsing and registration.
- QR-based check-in and attendance recording.
- Automatic certificate generation.
- Live crowd monitoring from Oracle data to JSP charts.
- Announcements and notification delivery.

## Integration rule

A feature belongs here when it crosses more than one technical workstream. Each integrated feature should include a request flow, service transaction, DAO behavior, view/API response, and test.

## Branch

Use `feature/fullstack/*` for end-to-end work before merging the completed feature into `main`.
